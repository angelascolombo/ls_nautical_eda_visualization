# LS Nautical: Profitability Analysis

🌐  Leia isto em [Português (BR)](README.pt-br.md)

---

This project combines SQL Analytics and Business Intelligence (BI) to conduct a deep financial diagnosis and performance analysis for a maritime supply company from 2023 to 2024.

The primary objective is to transform transactional and cost data into strategic indicators, exposing critical margin bottlenecks and delivering an interactive Power BI Executive Dashboard to support pricing restructuring and halt operational cash burn.

## 🛠️ Technologies

* **SQL:** Advanced querying, Common Table Expressions (CTEs), and Window Functions for financial metrics and seasonality analysis.
* **Power BI & DAX:** Development of the interactive management dashboard, RFM segmentation modeling, dynamic KPI alerts, and pricing scenario simulations.
* **Python (Matplotlib & Seaborn):** Static data visualizations.
* **Central Bank of Brazil API:** Direct integration to automate and update daily currency exchange rates (USD to BRL).
