# LS Nautical: Análise e Visualização de Dados

🌐  Read this in [English](README.md)

---

Este projeto combina análises em SQL e Business Intelligence (BI) para realizar um diagnóstico de receita e de performance de vendas de uma empresa de suprimentos marítimos, abrangendo o período de 2023 a 2024.

O objetivo principal é transformar dados transacionais e de custos em indicadores estratégicos, identificando gargalos críticos nas margens, além da entrega de um Dashboard Executivo interativo no Power BI para embasar a reestruturação de preços e conter a queima de caixa operacional.

## 🛠️ Tecnologias

* **SQL:** Consultas avançadas, Common Table Expressions (CTEs) e Window Functions para métricas financeiras e análise de sazonalidade.
* **Power BI e DAX:** Desenvolvimento de dashboard gerencial interativo, modelagem de segmentação RFM, alertas dinâmicos de KPIs e simulações de cenários de precificação.
* **Python (Matplotlib e Seaborn):** Visualizações de dados.
* **API do Banco Central:** Integração direta para automatizar e atualizar as taxas de câmbio diárias (USD para BRL).
